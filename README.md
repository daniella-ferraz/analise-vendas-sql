# analise-vendas-sql
Projeto de análise de vendas utilizando SQL, com consultas, filtros, agrupamentos e relacionamentos entre tabelas.

## Sobre o projeto

Este projeto foi desenvolvido para praticar SQL por meio da análise de dados de vendas.

O objetivo é utilizar consultas SQL para identificar informações importantes sobre os produtos, categorias, cidades e faturamento.

## Tecnologias utilizadas

- SQL
- SQLite
- GitHub

## Análises realizadas

Durante o projeto, foram realizadas consultas utilizando:

- SELECT
- WHERE
- LIKE
- IN
- ORDER BY
- GROUP BY
- HAVING
- funções de agregação
- UPDATE
- JOIN

## Principais informações analisadas

- Produtos vendidos
- Categorias de produtos
- Quantidade de produtos vendidos
- Preço dos produtos
- Faturamento
- Vendas por cidade
- Comparação entre categorias
- Relacionamento entre tabelas

## Estrutura do projeto

- analise-vendas.sql — arquivo contendo as consultas SQL utilizadas no projeto.

## Objetivo

O projeto faz parte do meu processo de aprendizado em Análise e Desenvolvimento de Sistemas, com foco no desenvolvimento de conhecimentos em SQL e análise de dados.
## Resultados da análise

A análise dos dados permitiu identificar os produtos vendidos, o faturamento por cidade e a distribuição das vendas por categoria.

Entre os principais resultados, foi possível observar:

- Identificação dos produtos com maior faturamento;
- Comparação das vendas entre as cidades;
- Análise das categorias de produtos;
- Identificação da quantidade de produtos vendidos;
- Cálculo do faturamento total;
- Utilização de consultas SQL para apoiar a análise dos dados.

## Conclusão

O projeto permitiu aplicar na prática conceitos de SQL e análise de dados, trabalhando com filtros, agrupamentos, funções de agregação e relacionamentos entre tabelas.

Esse projeto faz parte do meu processo de aprendizado em Análise e Desenvolvimento de Sistemas e representa uma prática dos conhecimentos adquiridos em SQL e análise de dados.
